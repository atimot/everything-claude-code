# ドキュメントの更新

信頼できるソースからドキュメントを同期します：

1. package.json の scripts セクションを読み取り
   - スクリプト参照テーブルを生成
   - コメントからの説明を含める

2. .env.example を読み取り
   - すべての環境変数を抽出
   - 目的とフォーマットを文書化

3. docs/CONTRIB.md を以下の内容で生成：
   - 開発ワークフロー
   - 利用可能なスクリプト
   - 環境セットアップ
   - テスト手順

4. docs/RUNBOOK.md を以下の内容で生成：
   - デプロイ手順
   - 監視とアラート
   - よくある問題と修正方法
   - ロールバック手順

5. 古いドキュメントを特定：
   - 90日以上更新されていないドキュメントを検索
   - 手動レビュー用にリスト化

6. 差分サマリーを表示

信頼できるソース: package.json と .env.example
